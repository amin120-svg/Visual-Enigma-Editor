# Visual Enigma Editor product mark

The simplified product mark is a folded V with a short editing cursor. It uses a flat teal shape and a light cursor, without the earlier metallic ornament. `vee-mark.svg` is the transparent mark; `vee-app-icon.svg` includes the slate application-icon background. Both are original vector assets created for VEE.

Use the vector mark next to the text “VEE” or “Visual Enigma Editor”. Exported PNG/ICO variants are application assets, not replacements for the supplied company logo. `py-snake-logo.png` remains the unchanged official Py Snake company image.
